# 技术栈规划

> 创建时间：2026-07-28

---

## 技术选型

| 层级 | 技术 | 选择理由 |
|---|---|---|
| 框架 | Next.js 15（App Router） | SSG 静态生成，SEO 友好，生态成熟 |
| 样式 | Tailwind CSS + shadcn/ui | 开发效率高，组件质量好 |
| 部署 | **Cloudflare Pages** | 纯静态导出首选，免费无限请求，全球 CDN，Git 自动部署 |
| 本地搜索 | Fuse.js | 纯前端搜索，无需后端 |
| SEO | next-sitemap | 自动生成 sitemap.xml |
| 国际化 | next-intl | Next.js 最佳 i18n 方案 |
| 语言检测 | navigator.language | 纯客户端，localStorage 缓存，详见 [05-语言检测方案.md](./05-语言检测方案.md) |

---

## 部署方案：Cloudflare Pages（唯一选项）

项目为**纯静态导出**（`output: 'export'`），无任何服务端代码，
所有请求均为静态文件请求，Cloudflare Pages **免费无限**。

```
next build → 生成 /out 静态文件 → push 到 GitHub → Cloudflare Pages 自动构建部署
```

| 对比项 | Cloudflare Pages | Cloudflare Workers Assets |
|---|---|---|
| 静态文件请求 | 无限免费 | 无限免费 |
| Worker 调用次数限制 | 无（我们没有服务端）| 无（我们没有服务端）|
| Git 自动部署 | ✅ 开箱即用 | 需手动配置 wrangler |
| 配置复杂度 | 低 | 中 |
| **结论** | **首选** | 将来需要边缘函数时再迁移 |

> Workers 与 Pages 代码完全兼容，将来迁移成本极低。

## 项目目录结构

```
web-tools/
├── app/
│   ├── [locale]/               # 国际化路由前缀
│   │   ├── page.tsx            # 首页（工具列表）
│   │   ├── tools/
│   │   │   ├── page.tsx        # 所有工具列表页
│   │   │   └── [slug]/
│   │   │       └── page.tsx    # 工具详情页（SEO 独立页面）
│   │   └── categories/
│   │       └── [category]/
│   │           └── page.tsx    # 分类页
│   └── layout.tsx              # 内联语言检测脚本放在此处
├── components/
│   ├── layout/                 # Header、Footer、LanguageSwitcher
│   ├── tools/                  # 各工具组件
│   │   ├── JsonFormatter.tsx
│   │   ├── Base64Tool.tsx
│   │   └── ...
│   └── ui/                     # 通用 UI 组件（shadcn）
├── lib/
│   ├── tools-registry.ts       # 工具注册表（元数据、分类、路由）
│   └── i18n/                   # 翻译文件（纯 JSON，客户端加载）
│       ├── en.json
│       ├── zh-CN.json
│       ├── zh-TW.json
│       ├── de.json
│       ├── ja.json
│       └── fr.json
├── docs/                       # 项目规划文档
├── next.config.ts              # output: 'export' 纯静态
└── public/
```
