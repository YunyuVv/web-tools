# 08 - 多语言国际化（i18n）规范

> 适用范围：本仓库所有页面、组件、工具。  
> 生效日期：2026-07-30  
> 关联文档：[07-路由与i18n URL规范.md](./07-路由与i18n URL规范.md) · [04-多语言市场.md](./04-多语言市场.md)

---

## 1. 总原则（必须）

**所有“面向用户可见的文字”一律走 i18n，禁止在 JSX / 配置文件里硬编码任何自然语言字符串。**

需要国际化的内容包括但不限于：

- 按钮文字（`复制` / `格式化` / `生成` …）
- 带文字的图标 / 图标按钮（`title`、`aria-label`）
- 表单标签、面板标题、区块标题
- 输入框 `placeholder`
- 提示文字、说明文字、空状态、状态栏
- 错误信息、校验提示
- 统计单位、计数模板（`{n} 字符`、`{count} 个匹配`）
- 下拉 / 分段控件的选项文字
- 导航、页脚、侧栏文案

**不翻译（保持原样）的例外：**

- 技术标识符 / 格式示例：`#6366F1`、`example.com`、`MD5`、`SHA256`、`UUID v4`、`OKLCH`、`HEX/RGB/HSL`、`Unix`、`ISO 8601`、`cron`、`CSS`、`JSON`、`Markdown`、`WCAG`、`IP` 等。
- 品牌名：`DevToolBox`。
- 代码 / 数据样例（示例文本、示例 JSON，属内容而非 UI chrome）。
- 人名、操作系统 / 浏览器 / 内核的英文品牌名（Windows、Edge、Chrome…）。

> **判断标准**：用户“看得到且会随语言变化”的文字，就必须走 `t()`。拿不准时，优先国际化。

---

## 2. 基础设施

- 翻译文件：`lib/i18n/{en,zh-CN,zh-TW}.json`（三语言键结构必须一致）。
- Provider：`components/layout/I18nProvider.tsx` 已在 `app/layout.tsx`、`app/[locale]/layout.tsx`、`app/(en)/layout.tsx` 三层包裹，**全站任意客户端组件均可使用**。
- Hook：
  ```tsx
  'use client'
  import { useI18n } from '@/components/layout/I18nProvider'

  function MyComponent() {
    const { t } = useI18n()
    return <button>{t('common.copy')}</button>
  }
  ```
- `t(key, fallback?)`：按点号路径取值；取不到时返回 `fallback`，再无则返回 `key` 本身（便于发现遗漏键）。

---

## 3. 命名空间约定

| 命名空间 | 用途 | 示例 |
|---|---|---|
| `common.*` | 跨工具通用按钮 / 状态 | `common.copy` `common.clear` `common.format` `common.error` `common.chars` |
| `nav.*` | 导航 | `nav.home` `nav.tools` |
| `home.*` | 首页 Hero / 搜索框 | `home.title` `home.search_placeholder` `home.search_hint` |
| `sidebar.*` | 侧栏 | `sidebar.collapse` `sidebar.soon` |
| `footer.*` | 页脚 | `footer.rights` |
| `categories.*` | 分类名 | `categories.json` `categories.encoding` |
| `tools.<slug>.*` | 各工具专属 | `tools.json-formatter.title` `tools.timestamp.input_placeholder` |

**规则：**

- 通用动作（`copy` / `clear` / `format` / `validate` / `minify` / `swap` / `encode` / `decode` / `sample` / `generate` / `regenerate` …）放 `common.*`，所有工具共用。
- 工具专属文案（标题、输入/输出标签、占位符、模式选项、状态、错误）放 `tools.<slug>.*`，键名与 `lib/tools-registry` 的 `i18nKey` 对齐。
- 同一语义三语言文案不同，但**键名完全一致**。

---

## 4. 占位符 / 模板插值

`t()` 只做键查找，**不支持自动插值**。模板字符串在调用处手动替换：

```tsx
// 单值
t('tools.timestamp.label_unix_sec')                 // 直接取
t('home.search_results_count').replace('{count}', String(n))
t('tools.regex-tester.error_prefix').replace('{error}', errMsg)

// 多值
t('tools.password-generator.entropy')
  .replace('{bits}', String(bits))
  .replace('{len}', String(len))

// 模板里含 {mode} 这类“取另一个键”的：
t('common.theme_toggle').replace('{mode}', t('common.theme_' + current))
```

> ⚠️ 嵌套键名用字符串拼接（`'common.theme_' + current`），**不要**在模板字符串里套反引号调用 `t(`…`)`。

---

## 5. 禁止在模块级 / 工具函数里调用 `t`

`t` 依赖 React Context，只能在**组件函数体内**（或其渲染作用域）调用。

错误示例（会运行时报错 / 取到空上下文）：

```tsx
// ❌ 模块级常量或工具函数里直接调 t
const SAMPLE = t('tools.regex-tester.sample_text')   // 模块加载时 Context 尚不存在
function describe(cron) { return t('tools.cron-parser.desc_custom') }  // 工具函数无 Context
```

正确做法（三选一）：

1. 将文案拆成 `i18nKey` 字段，渲染时再 `t(field.i18nKey)`；
2. 把 `t` 作为参数传给工具函数：`describe(cron, t)`；
3. 工具函数返回**英文 token**（如 `unknown` / `desktop`），组件内再 `t('tools.user-agent.' + token)` 映射。

> 本仓库已踩坑：模块级 `function convert()` 内调用 `t` 会导致 `ReferenceError: t is not defined`。务必遵守。

---

## 6. 新增键的流程

1. 在 `lib/i18n/en.json` 加英文键（源语言）。
2. **同步**加到 `zh-CN.json`（简中）、`zh-TW.json`（繁中），键路径与结构完全一致。
3. 若工具组件里新增了 UI 文案，键放在 `tools.<slug>.*`。
4. 改完用 `node -e "JSON.parse(require('fs').readFileSync('lib/i18n/en.json','utf8'))"` 校验三个 JSON 合法（避免逗号 / 引号错误导致整页崩溃）。

---

## 7. 服务端组件取文案

- 页面（`app/.../page.tsx`）在服务端加载整本字典，通过 `messages` prop 下发给子组件（如 `ToolsHomePage` 的 `home` / `tools` / `sidebar` 字段）。
- 服务端组件**不要** `import` 客户端 `useI18n`（会破坏 RSC）；如需在布局级取文案，要么接收 `messages` prop，要么把该组件标 `'use client'` 后用 `useI18n()`。
- 客户端子组件的兜底 fallback：优先用上层传入的 `messages` 文案；仅当确实缺失时，用 `t('...')` 兜底（参考 `HomeSearch` 的 fallback 写法）。

## 9. 示例

**Before（硬编码，错误）：**

```tsx
<button onClick={copy} title="复制">{copied ? '已复制' : '复制'}</button>
<input placeholder="在此输入 JSON…" />
```

**After（国际化，正确）：**

```tsx
'use client'
import { useI18n } from '@/components/layout/I18nProvider'

function JsonPanel() {
  const { t } = useI18n()
  return (
    <>
      <button onClick={copy} title={t('common.copy')}>
        {copied ? t('common.copied') : t('common.copy')}
      </button>
      <input placeholder={t('tools.json-formatter.input_placeholder')} />
    </>
  )
}
```
