# 多语言与目标市场规划

> 创建时间：2026-07-28

---

## 核心思路

语言优先级 = 广告 CPM × 开发者用户规模 × 竞争烈度

不是翻译越多越好，而是先把高价值语言做精，再逐步扩展。

---

## 第一优先级：必须支持（上线即有）

### 英语（en）
| 项目 | 详情 |
|---|---|
| 目标国家 | 美国、英国、加拿大、澳大利亚、新西兰 |
| 广告 CPM | $15 - $50（最高） |
| 开发者规模 | 全球最大 |
| 竞争烈度 | 高，但流量池极大 |
| 重要性 | ⭐⭐⭐⭐⭐ 必须，且是 SEO 基础 |

**英语是整个站点的基础，所有工具以英语为主语言，其他语言为补充。**

### 简体中文（zh-CN）
| 项目 | 详情 |
|---|---|
| 目标国家 | 中国大陆 |
| 广告 CPM | ¥1 - ¥5（折合 $0.1 - $0.7） |
| 开发者特点 | 开发者基数极大，工具依赖度高 |
| 竞争烈度 | 高（工具站成熟） |
| 变现方式 | AdSense 效果差，可考虑国内广告联盟（如百度联盟） |
| 语言检测 | IP 归属 CN → 自动跳转简体中文 |
| 重要性 | ⭐⭐⭐ 开发者自用，流量基础盘 |

### 繁体中文（zh-TW）
| 项目 | 详情 |
|---|---|
| 目标国家 | 台湾、香港、澳门 |
| 广告 CPM | $3 - $12 |
| 开发者特点 | 台湾科技业发达，香港金融科技需求旺 |
| 竞争烈度 | 中低 |
| 语言检测 | IP 归属 TW / HK / MO → 自动跳转繁体中文 |
| 重要性 | ⭐⭐⭐ 比简体中文 CPM 高，且竞争更低 |

## 语言上线优先级汇总

```
第一批（上线即有）：
  英语（en）    ← 必须，SEO 基础，非中国 IP 默认展示
  简体中文（zh-CN）← 中国大陆 IP 自动检测跳转
  繁体中文（zh-TW）← 台湾 / 香港 / 澳门 IP 自动检测跳转

第二批（上线后 1-2 个月）：
  德语（de）← 高 CPM + 低竞争
  日语（ja）← 亚洲最优先
  法语（fr）← 欧洲体量

第三批（3-6 个月）：
  荷兰语（nl）
  葡萄牙语（pt-BR）
  西班牙语（es）
  韩语（ko）

第四批（按需扩展）：
  瑞典语（sv）
  挪威语（nb）
  波兰语（pl）
```

## 翻译策略

### 需要翻译的内容

| 内容 | 翻译方式 | 说明 |
|---|---|---|
| 导航、按钮、标签 | 人工校对 | 量少，质量要求高 |
| 工具说明（短文本）| 人工校对 | 影响 SEO，必须准确 |
| 工具 SEO 描述 | AI 翻译 + 人工审核 | 每页 100-200 字 |
| 工具操作区 UI | AI 翻译 | 按钮文字等 |

### 不需要翻译

- 代码输入输出内容（编程语言通用）
- 技术术语（如 JSON、Base64、UUID 保持英文）
- 错误信息中的技术细节

### 翻译文件结构

```json
// messages/en.json（示例）
{
  "common": {
    "copy": "Copy",
    "clear": "Clear",
    "download": "Download",
    "paste": "Paste"
  },
  "tools": {
    "json-formatter": {
      "title": "JSON Formatter",
      "description": "Format and validate JSON online",
      "input_placeholder": "Paste your JSON here...",
      "seo_description": "Free online JSON formatter..."
    }
  }
}
```

## hreflang SEO 配置

每个工具页面需要添加 hreflang 标签，告知 Google 各语言版本：

```html
<link rel="alternate" hreflang="en"    href="https://devtoolbox.io/tools/json-formatter" />
<link rel="alternate" hreflang="zh-CN" href="https://devtoolbox.io/zh-CN/tools/json-formatter" />
```
