## 1. Show HN（Hacker News）

**标题**
```
Show HN: DevToolBox – 23 developer tools that run 100% in your browser
```

**正文**
```
Most "online tool" sites quietly send your text, payloads, or secrets to a
server. DevToolBox doesn't have a server at all — every tool runs locally in
the browser, so your data never leaves the tab.

It's a collection of 23 small utilities developers reach for daily:

- JSON formatter / inspector / JSON→CSV
- Base64, URL encode, HTML entities, args formatter
- Hash (MD5/SHA), UUID, password generator
- Regex tester, word counter, markdown preview, lorem ipsum
- Unix timestamp ↔ human, cron parser
- CSS gradient / box-shadow builders
- Color converter / WCAG contrast checker
- IP lookup, user-agent parser
- Avatar generator

Why it's nice to use:
- No login, no backend, no tracking. Free, ad-supported (no paywall).
- Truly multilingual: full English / 简体中文 / 繁體中文 with proper hreflang.
- Light & dark mode, instant results, works offline after first load.
- Open source (MIT) — you can audit or self-host it.

Built with Next.js 16 (static export) on Cloudflare Pages.

Live: https://tools.ideaflow.top
Source: https://github.com/YunyuVv/web-tools

Feedback and tool requests welcome.
```

## 2. V2EX（节点：分享创造）

**标题**
```
做了一个纯前端、数据不出浏览器的开发者工具箱（23 个工具，已开源）
```

**正文**
```
不知道大家有没有过这种顾虑：在线的 JSON 格式化、Base64 解码、密码生成器，
输进去的内容其实都被传到对方服务器了。

所以我做了 DevToolBox —— 一个**完全在浏览器本地运行**的开发者工具箱，
没有后端，你输入的任何内容都不会离开你的浏览器标签页。

目前有 23 个常用小工具：

- JSON 格式化 / 结构查看 / 转 CSV
- Base64、URL 编码、HTML 实体、参数格式化
- 哈希（MD5/SHA）、UUID、密码生成器
- 正则测试、字数统计、Markdown 预览、Lorem Ipsum
- 时间戳转换、Cron 表达式解析
- CSS 渐变 / 阴影生成器
- 颜色转换 / WCAG 对比度检查
- IP 查询、User-Agent 解析
- 头像生成

特点：
- 免登录、无后端、不追踪，免费（有广告但无付费墙）
- 完整中英繁三语， SEO 做了 hreflang
- 亮/暗色主题，本地计算秒出结果
- 已开源（MIT），可以自己部署或审计

地址：https://tools.ideaflow.top
源码：https://github.com/YunyuVv/web-tools

欢迎提建议或想要的工具～
```
