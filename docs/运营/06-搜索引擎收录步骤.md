# 搜索引擎收录步骤（Google + Bing）

> 创建时间：2026-08-08
> 配套：[02-SEO与推广运营方案.md](./02-SEO与推广运营方案.md)（本项目已落地的 SEO 基建与 GSC/Bing 实操细节）
> 适用范围：新站首次提交收录，或改版/加页面后刷新收录。示例域名统一用本项目的 `tools.ideaflow.top`。

---

## 〇、先搞清楚"收录"是什么

提交 ≠ 一定被收录。整个过程分三步，提交只影响第一步：

1. **发现（Discovery）**：搜索引擎知道这个 URL 存在。→ 提交 sitemap / IndexNow 主要作用于此。
2. **抓取（Crawling）**：爬虫（Googlebot / Bingbot）真的来读页面。
3. **收录（Indexing）**：搜索引擎决定把页面放进索引、允许出现在结果里。**最终是否收录由引擎按内容质量判定，谁都无法强制。**

所以正确预期：提交 sitemap + 主动通知，只能"加速被发现"，不能"保证被索引"。内容与结构做好了，收录才稳。

## 一、收录前准备（必做，否则白提交）

| 准备项 | 说明 | 本项目现状 |
|---|---|---|
| 可访问的 `sitemap.xml` | 列出全部要收录的 URL，公开可访问、未被 robots.txt 拦截 | 已落地 `scripts/generate-sitemap.mjs`，构建产物 `out/sitemap.xml`（74 个 URL） |
| 正确的 `robots.txt` | `Allow: /` 且最好加 `Sitemap: https://tools.ideaflow.top/sitemap.xml`，让爬虫自首页/TXT 就能找到地图 | 已落地 |
| 无抓取障碍 | 页面无登录墙、状态码 200、无 `noindex`、canonical 正确、关键内容 SSR（本项目 `output:'export'` 静态页天然满足） | 已满足 |
| 站点可验证所有权 | 能改 DNS / 上传文件 / 加 meta 标签 | Cloudflare 托管，DNS 可改 |

> 没有 sitemap 也能被收录（靠外链发现），但新站/深页面会慢几周甚至几个月。sitemap 是把全部 URL 一次性摆到引擎面前的最快方式。

## 二、Google 收录步骤

### 具体网站（Google 侧）

| 用途 | 网址 |
|---|---|
| Google Search Console 主页 | https://search.google.com/search-console/ |
| 站点地图提交页 | https://search.google.com/search-console/sitemaps |
| 网址检查（查收录 / 请求编入索引） | https://search.google.com/search-console/inspect |
| Google 站点地图官方说明 | https://support.google.com/webmasters/answer/7451001 |

### 步骤

1. **打开 GSC 并添加资源**
   - 访问 [Google Search Console](https://search.google.com/search-console/)，用与站点同主体的 Google 账号登录。
   - 左侧「搜索资源」→「添加资源」。两种类型：
     - **网域（Domain）**：输 `tools.ideaflow.top`（不带协议），用 **DNS TXT 验证**，一次性覆盖所有子域 + http/https 变体 → **推荐**。
     - **网址前缀（URL prefix）**：输 `https://tools.ideaflow.top/`（带末尾斜杠），可用 HTML 文件 / meta / GA 验证，但 www 与非 www 要分别添加。

2. **验证所有权**（按所选类型选一种）
   - **DNS 验证（推荐）**：复制 GSC 给的 `google-site-verification=XXXX` → 到 Cloudflare（本项目域 `tools.ideaflow.top`）→ DNS → 加 TXT 记录（主机名 `@`）→ 回 GSC 点「验证」。
   - **HTML 文件验证**：下载 `google*.html` → 放进 `public/` → 重新构建进 `out/` 根目录 → 确认 `https://tools.ideaflow.top/google*.html` 可达 → 验证。
   - **meta 标签验证**：把 `<meta name="google-site-verification" content="XXXX">` 加到 `app/layout.tsx` 的 `<head>`（需重新部署）。

3. **提交 sitemap**
   - 进 [站点地图页](https://search.google.com/search-console/sitemaps)，在「添加新站点地图」框输入 **`sitemap.xml`**（只填文件名，不要带域名）→ 提交。
   - 状态「成功」= Google 已接收；「已发现网址数」会随抓取增长。
   - 旧 sitemap 有错（如本项目的 `...toptools/...` URL 拼接 bug）：先修代码，再删除旧 sitemap → 重新提交。

4. **查收录 / 请求编入索引**
   - 进 [网址检查页](https://search.google.com/search-console/inspect)，粘贴具体页面 URL（如 `https://tools.ideaflow.top/zh-CN/tools/json-formatter/`）→ 看是否被编入索引。
   - 若未收录且页面重要，点 **「请求编入索引」**。注意：**每日配额约 200 条**，只给首页和 Top 10–20 关键页用，别刷。
   - 几天后仍不收录：用「网址检查 → 请求编入索引」定向催一下；是否收录仍由 Google 判定。

5. **验证是否真的收录**
   - 在 Google 搜索框输入 `site:tools.ideaflow.top` → 看「约 X 条结果」，这是最可靠的口径。
   - GSC 「索引」→「网页索引报告（Coverage）」也能看已收录 / 已排除 / 错误 / 待处理四类状态。

> ⚠️ **两大误区**
> - Google **Indexing API 官方仅支持 JobPosting / BroadcastEvent 结构化数据页面**，不是通用"提交收录"捷径。普通工具站靠 sitemap + 网址检查催录即可。
> - Google **已不支持**老的 `google.com/ping?sitemap=` 主动 ping；提交途径只剩 GSC UI 和在 `robots.txt` 写 `Sitemap:` 指令。

## 三、Bing 收录步骤

### 具体网站（Bing 侧）

| 用途 | 网址 |
|---|---|
| Bing Webmaster Tools 主页 | https://www.bing.com/webmasters |
| Bing 站点地图提交页 | https://www.bing.com/webmasters/sitemaps |
| Bing URL 提交（单条 / 批量，每日限额） | 在 Webmaster 左侧菜单 → **URL Submission** |
| IndexNow 官网（协议说明 + key 生成） | https://www.indexnow.org/ |
| IndexNow 统一提交 API 端点 | https://api.indexnow.org/indexnow |

> Bing 的索引还支撑 **Yahoo、DuckDuckGo、Microsoft Copilot、ChatGPT Search** 等使用 Bing 索引的渠道。收录 Bing ≈ 同时覆盖这些。2026 年起 Bing WMT 还提供 AI 引用（AI Performance）报表。

### 步骤

0. **前置（可选但推荐）：先完成上面的 Google Search Console 验证** → 可直接"从 GSC 导入"跳过手动验证。

1. **打开 Bing Webmaster Tools 并登录**
   - 访问 [Bing Webmaster Tools](https://www.bing.com/webmasters)，用 **Microsoft 账号**登录（Outlook/Hotmail 即可，个人站足够）。

2. **添加站点**
   - 点「**添加站点**」，填 `https://tools.ideaflow.top`。
   - **最快路径（推荐）**：若已关联 Google 账号，Bing 会列出你在 GSC 已验证的站点，点「**导入**」一键拉入，自动复用 GSC 验证，省去第 3 步。

3. **验证所有权**（四种方式任选其一）
   - **方式 A（最省事）：从 Google Search Console 导入** → 授权后勾选 `tools.ideaflow.top`，秒过。
   - **方式 B（最快手动）：XML 文件验证** → 下载 `BingSiteAuth.xml` 放 `public/` → 重新构建进 `out/` → 确认 `https://tools.ideaflow.top/BingSiteAuth.xml` 可达 → 验证。
   - **方式 C：CNAME 验证** → 加一条指向 `verify.bing.com` 的 CNAME（Cloudflare 可加）。
   - **方式 D：meta 标签验证** → 把 `<meta name="msvalidate.01" content="XXXX">` 加到 `app/layout.tsx` 的 `<head>`（需重新部署）。

4. **提交 sitemap**
   - 进 [Bing 站点地图页](https://www.bing.com/webmasters/sitemaps)，在输入框填 **完整 URL** `https://tools.ideaflow.top/sitemap.xml`（Bing 要完整地址，不像 GSC 只填文件名）→ 添加。
   - 提交后能看到「已发现 URL 数」和处理进度。Bing 也接受 RSS / Atom / 纯文本（每行一个 URL）格式。

5. **（强烈推荐）用 IndexNow 主动通知，收录快 10 倍**
   - 普通 sitemap 提交后 Bing 仍按队列爬；想让新页面**当天被抓取**，用 IndexNow 主动 ping。
   - **统一端点** `https://api.indexnow.org/indexnow`：一次调用自动转发 Bing + Yandex + Naver + Seznam + 互联网档案等参与引擎（**Google 未加入该协议**）。
   - **本项目已落地零依赖方案**：`public/<key>.txt`（key 验证文件）+ `scripts/submit-indexnow.mjs`（构建后读 `out/sitemap.xml` 批量 POST），且仅在 `CF_PAGES==='true'` 或 `SUBMIT_INDEXNOW==='true'` 时才真发（详见 `02-SEO与推广运营方案.md` 第二节第 5 点）。
   - 手动也可：Bing Webmaster →「配置我的站点」→「通过 IndexNow 提交 URL」贴单条或传列表。

6. **查收录 / 诊断**
   - 仪表板「**URL 检查（URL Inspection）**」：贴具体页 URL 看索引状态、最近抓取时间、被拦截资源。
   - 「**索引资源管理器**」：结构化浏览已发现 URL、抓取问题、重定向、被 robots 拦截的页。
   - 「**报表和数据**」→ SEO 报告 / 入站链接 / 爬取信息：看爬取错误、关键词、Bingbot 频次与响应码。

> ⚠️ Bing **也没有"请求重新收录"公开接口**。改版后让 Bing 重抓靠：① 刷新 sitemap + ② IndexNow 主动通知；是否收录由 Bing 按质量判定。

## 五、加速收录的实用技巧

1. **高质量外链**：从已被收录的站（GitHub、社区帖、友情链接）指回，引擎顺着链接更快发现你。
2. **主动通知优先于被动等**：新站/新页用 IndexNow（Bing）或 GSC 网址检查催录（Google），别干等爬虫。
3. **sitemap 保持新鲜且诚实**：`lastmod` 写真实修改时间，别每次部署全改今天，否则引擎学会忽略。
4. **robots.txt 写好 `Sitemap:` 指令**：双保险，爬虫每次抓取都能拿到地图位置。
5. **内部链接成网**：重要页从首页/导航可达，无内链的"孤岛页"难被发现。
6. **修好技术债**：404、5xx、noindex、错误 canonical 会让引擎放弃整块内容；先清错再催录。

## 六、常见问题

- **提交了几天还没收录？** 正常现象。Google 新域常需数天到 2–4 周；Bing + IndexNow 通常 24h 内。先用 `site:` 确认，再对关键页单独催录。
- **sitemap 报"不允许的网址"？** URL 拼接/域名错了（本项目踩过 `...toptools/...` 的坑）。先修代码 → 删旧 sitemap → 重新提交。
- **Google 和 Bing 要分别做吗？** 是，两套独立索引。但 Bing 可从 GSC 一键导入验证，省一半事；IndexNow 还能一次通知多家（除 Google）。
- **有没有 MCP 能自动化？** Google 无官方 GSC MCP（社区版可查状态）；Bing 无官方 MCP，可用 IndexNow MCP / Bing Webmaster MCP 批量推送。详见 `02-SEO与推广运营方案.md` 与 `03-数据分析与谷歌 MCP 工具.md`。
