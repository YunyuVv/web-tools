# 语言检测方案

> 创建时间：2026-07-28  
> 更新时间：2026-07-28

---

## 方案定性

**纯前端静态方案，无任何服务端逻辑。**

- Next.js 使用 `output: 'export'` 静态导出
- 无 middleware.ts
- 语言检测完全在客户端完成
- 偏好存 `localStorage`，第二次起零闪烁

---

## 闪烁问题分析

```
普通客户端检测流程：
  请求 → 返回 HTML → 渲染英文页面 → JS 加载 → 检测语言 → 跳转中文
                                    ↑
                               用户看到英文（闪烁）

加入内联脚本后：
  请求 → 返回 HTML → <head> 内联脚本同步执行 → 直接跳转中文
                      ↑
                 React 还没渲染，用户什么都没看到（无闪烁）
```

**内联脚本放在 `<head>` 中同步执行，阻塞渲染，检测完成前页面不会显示任何内容，因此没有闪烁。**

第一次访问也无闪烁，同时把结果写入 `localStorage`，后续直接读缓存，更快。

// next.config.ts
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  output: 'export',   // 纯静态导出，无服务端
  trailingSlash: true,
}

export default nextConfig

## 内联检测脚本（核心，放在 head 最前面）

```typescript
// app/layout.tsx

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html>
      <head>
        {/* 放在最前面，同步执行，阻塞渲染，消除闪烁 */}
        <script dangerouslySetInnerHTML={{ __html: `
          (function () {
            var SUPPORTED = ['zh-CN', 'zh-TW', 'de', 'ja', 'fr'];
            var ZH_TW = ['zh-TW', 'zh-Hant', 'zh-HK', 'zh-MO'];
            var ZH_CN = ['zh-CN', 'zh-Hans', 'zh-SG', 'zh'];

            // 1. 读 localStorage 缓存的偏好
            var locale = localStorage.getItem('NEXT_LOCALE');

            // 2. 没有缓存，用 navigator.language 检测
            if (!locale) {
              var lang = navigator.language || navigator.languages && navigator.languages[0] || '';
              if (ZH_TW.some(function(l){ return lang.startsWith(l); })) locale = 'zh-TW';
              else if (ZH_CN.some(function(l){ return lang.startsWith(l); })) locale = 'zh-CN';
              else if (lang.startsWith('de')) locale = 'de';
              else if (lang.startsWith('ja')) locale = 'ja';
              else if (lang.startsWith('fr')) locale = 'fr';
              else locale = 'en';

              // 写入缓存，下次直接用，不再检测
              localStorage.setItem('NEXT_LOCALE', locale);
            }

            // 3. 如果当前 URL 没有正确的 locale 前缀，立即跳转
            var path = window.location.pathname;
            var hasLocale = SUPPORTED.some(function(l) {
              return path === '/' + l || path.startsWith('/' + l + '/');
            });

            if (!hasLocale && locale !== 'en') {
              // replace 而非 push，跳转后按返回键不会回到错误语言页
              window.location.replace('/' + locale + path);
            }
          })();
        ` }} />
      </head>
      <body>{children}</body>
    </html>
  )
}
```

## 完整流程

```
第一次访问 /tools/json-formatter
    ↓
<head> 内联脚本同步执行（React 未渲染）
    ↓
读 localStorage → 空
    ↓
读 navigator.language → 'zh-CN'
    ↓
写入 localStorage: NEXT_LOCALE = 'zh-CN'
    ↓
window.location.replace('/zh-CN/tools/json-formatter')
    ↓
渲染中文页面（用户无感知闪烁）

---

第二次及以后访问 /tools/json-formatter
    ↓
<head> 内联脚本同步执行
    ↓
读 localStorage → 'zh-CN'（有缓存）
    ↓
window.location.replace('/zh-CN/tools/json-formatter')
    ↓
渲染中文页面（零延迟，零闪烁）

---

用户在 /zh-CN/... 页面访问（URL 已含 locale）
    ↓
<head> 脚本检测到 URL 已有 locale 前缀
    ↓
不跳转，直接渲染当前页面
```

## 语言切换组件

用户手动切换语言时，更新 localStorage 并跳转：

```typescript
// components/LanguageSwitcher.tsx
'use client'

import { useRouter, usePathname } from 'next/navigation'

const LOCALES = [
  { code: 'en',    label: 'English' },
  { code: 'zh-CN', label: '简体中文' },
  { code: 'zh-TW', label: '繁體中文' },
  { code: 'de',    label: 'Deutsch' },
  { code: 'ja',    label: '日本語' },
  { code: 'fr',    label: 'Français' },
]

const LOCALE_PATTERN = new RegExp(
  `^/(${LOCALES.map(l => l.code).join('|')})(\/|$)`
)

export function LanguageSwitcher({ currentLocale }: { currentLocale: string }) {
  const router = useRouter()
  const pathname = usePathname()

  const switchLocale = (locale: string) => {
    // 更新 localStorage，下次访问直接用
    localStorage.setItem('NEXT_LOCALE', locale)

    // 去掉当前 URL 的 locale 前缀，拼接新的
    const newPath = pathname.replace(LOCALE_PATTERN, '/') || '/'
    router.push(locale === 'en' ? newPath : `/${locale}${newPath}`)
  }

  return (
    <select value={currentLocale} onChange={e => switchLocale(e.target.value)}>
      {LOCALES.map(l => (
        <option key={l.code} value={l.code}>{l.label}</option>
      ))}
    </select>
  )
}
```

## 语言匹配规则

| navigator.language 值 | 匹配结果 |
|---|---|
| `zh-CN`, `zh-Hans`, `zh-SG`, `zh` | zh-CN（简体中文）|
| `zh-TW`, `zh-Hant`, `zh-HK`, `zh-MO` | zh-TW（繁体中文）|
| `de`, `de-DE`, `de-AT` | de（德语）|
| `ja`, `ja-JP` | ja（日语）|
| `fr`, `fr-FR` | fr（法语）|
| 其他所有 | en（默认英文，不跳转）|

// 浏览器控制台 — 模拟中文用户
localStorage.setItem('NEXT_LOCALE', 'zh-CN'); location.reload()
