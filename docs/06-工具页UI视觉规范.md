# 工具页 UI 视觉规范（Base64 / URL 编解码）

> 创建时间：2026-07-30  
> 适用范围：`Base64Tool.tsx`、`UrlEncodeTool.tsx` 及其共用的 `SlidingSegmented` 组件  
> 目标：统一工具页的视觉语言，作为后续同类工具页（时间戳、UUID、哈希、字数统计等）的对齐基准

---

## 1. 设计理念

| 原则 | 说明 |
|---|---|
| 简洁克制 | 工具页**跳过页头眉批 / 标题 / 描述 / SEO 文本块**，首屏直接展示功能；不堆叠装饰。 |
| 有呼吸感 | 通过放大留白（外层 `gap-6`、面板内边距 `px-5 py-4`、文本框 `min-h-[360px]`、行高 `leading-7`）制造舒展感，而非靠阴影和描边。 |
| 明暗自适应 | 全部颜色走 shadcn/ui 的 oklch 主题变量（`border` / `muted` / `card` / `primary` / `destructive`…），深浅主题无需单独写两套色值。 |
| 零依赖 | 不引入 `framer-motion` 等动画库；交互与过渡用纯 CSS + 原生 pointer / keyboard 事件实现。 |

> 视觉基调：**减少装饰、直接给功能、克制而现代化**。新增动态效果时优先轻量、不喧宾夺主。

---

## 2. 整体布局骨架

两个页面共用同一套布局结构（自上而下）：

```
┌──────────────────────────────────────────────────────────┐
│  顶部工具栏： [滑动玻璃分段控件]    …右对齐按钮组…          │
├──────────────────────────────────────────────────────────┤
│  （可选）错误提示条                                         │
├──────────────────────────────┬───────────────────────────┤
│  左面板：输入区               │  右面板：输出区（只读）     │
│   header（标题 + 字数徽章）    │   header（标题 + 复制按钮） │
│   ┌────────────────────┐      │   ┌────────────────────┐   │
│   │  textarea          │      │   │  textarea（只读）   │   │
│   └────────────────────┘      │   └────────────────────┘   │
└──────────────────────────────┴───────────────────────────┘
```

| 区块 | 容器类 | 关键点 |
|---|---|---|
| 根容器 | `flex flex-col gap-6` | 三段之间统一留白 24px。 |
| 顶部工具栏 | `flex items-center gap-3 flex-wrap` | 左侧分段控件，`flex-1` 推开右侧按钮组（示例 / 交换 / 清空）。 |
| 双栏工作区 | `grid grid-cols-1 gap-5 lg:grid-cols-2 lg:gap-6` | 移动端单列、≥lg 双列；双栏间距桌面 24px、移动 20px。 |
| 面板 | `group rounded-2xl border border-border/60 bg-card overflow-hidden transition-colors focus-within:border-primary/40` | 圆角统一 `rounded-2xl`；聚焦时边框浮起青绿色；无生硬投影。 |

## 3. 滑动玻璃分段控件（SlidingSegmented）

文件：`components/ui/SlidingSegmented.tsx`（零依赖、泛型 `<T extends string>`）。

### 3.1 外观

- **轨道**：`relative inline-flex touch-none select-none items-center rounded-full border border-border/60 bg-muted/40 p-1`。
- **玻璃滑块**：绝对定位、`left-0 top-1 bottom-1`、`rounded-full`，样式为
  `bg-white/70 shadow-sm ring-1 ring-inset ring-white/60 shadow-[inset_0_1px_0_rgba(255,255,255,0.65)] backdrop-blur-md`
  `dark:bg-white/10 dark:ring-white/10` —— 浅色用半透明白 + 高光 inset，深色换 `bg-white/10`，整体呈轻量液体玻璃感。
- **分段按钮**：`relative z-10 rounded-full px-5 py-2 text-sm font-medium`，激活态 `text-foreground`、非激活 `text-muted-foreground hover:text-foreground`。

### 3.2 交互

| 行为 | 实现要点 |
|---|---|
| 点击切换 | 按钮 `onClick` → `onChange(value)`；滑块 CSS 过渡滑入对齐。 |
| 拖拽跟手 | `onPointerDown` 捕获分段几何快照，`pointermove` 实时插值 `left` + `width`（**位置与宽度同步**，长短不一选项也能平滑过渡）；拖动时 `transition-none`，1:1 跟手。 |
| 松手吸附 | 用指针实时坐标找最近分段，显式 `setPill` 落位（即使值不变也保证视觉归位），再触发 `onChange`。 |
| 键盘 | `role="radiogroup"` + 各按钮 `role="radio" aria-checked` + 漫游 tabindex；方向键 / Home / End 切换并 `focus()`。 |

### 3.3 缓动与对齐

- 静止过渡：`transition-[transform,width] duration-300 ease-[cubic-bezier(0.2,0.9,0.24,1)]`（零依赖近似弹簧，无需 framer-motion）。
- 对齐机制：滑块用 `seg.offsetLeft / offsetWidth`（与绝对定位同源）对齐激活项；`ResizeObserver` + `document.fonts.ready` 防止响应式 / 字体加载后错位；`ready` 前 `opacity:0` 避免 SSR 闪位。

### 3.4 复用接口

```tsx
<SlidingSegmented
  ariaLabel="编码或解码模式"
  value={mode}
  onChange={setMode}
  options={[
    { value: 'encode', label: '编码' },
    { value: 'decode', label: '解码' },
  ]}
/>
```

## 4. 面板（Panel）细则

两个页面的输入 / 输出面板共用同一套面板样式，差异仅在 header 内容与图标。

### 4.1 Header 条

```
flex items-center justify-between border-b border-border/40 bg-muted/20 px-5 py-3 text-xs
```

- 左：标题（图标 + 文案），如 `{Unlock} 原始文本` / `Base64 结果`。
- 右：**统计徽章**或**复制按钮**。
  - 统计徽章：`rounded-md bg-background/70 px-2 py-0.5 font-mono tabular-nums text-muted-foreground`（等宽数字，避免跳动）。
  - 复制按钮：`rounded-full border border-border/60 px-3 py-1 text-xs`，复制成功切换为 `{Check} 已复制`（`text-green-500`）。

### 4.2 文本区（textarea）

```
w-full resize-none border-0 bg-transparent px-5 py-4 font-mono text-sm leading-7
focus:outline-none placeholder:text-muted-foreground/60 min-h-[360px]
```

- 等宽字体 + 行高 `leading-7`（1.75）保证可读性；`resize-none` 锁定尺寸由面板控制；只读输出区加 `select-all cursor-default`。

## 5. 按钮规范

顶部工具栏按钮（示例 / 交换 / 清空）统一外观：

```
inline-flex items-center gap-1.5 rounded-full border border-border/60 px-4 py-2 text-sm
text-muted-foreground transition hover:border-primary/40 hover:text-foreground cursor-pointer
disabled:opacity-40 disabled:cursor-not-allowed
```

| 按钮 | 差异 |
|---|---|
| 示例 / 交换 | hover 边框浮起 `primary/40`；禁用态 `opacity-40`。 |
| 清空 | hover 边框 / 文字变 `destructive`（`hover:border-destructive/40 hover:text-destructive`）。 |
| 复制（面板内） | 小号 `px-3 py-1 text-xs`，圆角仍为 `rounded-full`。 |

图标取自 `lucide-react`（`Sparkles` / `ArrowLeftRight` / `Trash2` / `Copy` / `Check` / `Lock` / `Unlock`），尺寸 `h-3.5`~`h-4`。

## 6. 错误态（Error）

| 元素 | 样式 |
|---|---|
| 顶部错误条 | `rounded-xl border border-destructive/30 bg-destructive/5 px-4 py-2.5 text-xs text-destructive`；URL 页用 `font-mono`，Base64 页加粗前缀「错误：」。 |
| 输出区红框（仅 Base64） | 解码失败时输出面板 `border-destructive/40 bg-destructive/[0.03]`，输入文字 `text-destructive/80`。 |
| 文案 | 解码非法输入时给出明确中文提示（如「无效的 Base64 字符串，请检查输入格式」）。 |

## 7. 颜色令牌（明暗自适应）

| Token | 用途 | 明暗表现 |
|---|---|---|
| `border` | 面板 / 按钮描边（`/60` 透明度） | 自动跟随主题 |
| `muted` | 分段轨道底、面板 header 底（`/20`~`/40`） | 自动跟随主题 |
| `muted-foreground` | 次要文字、统计徽章、按钮默认色 | 自动跟随主题 |
| `card` / `background` | 面板底 / 徽章底 | 自动跟随主题 |
| `primary` | 滑块高光、聚焦边框浮起（`border-primary/40`）、图标色 | 品牌青绿 |
| `destructive` | 清空 hover、错误文字 / 边框 | 红 |
| `green-500` | 复制成功图标与文字 | 固定绿 |

> 玻璃滑块例外：浅色 `bg-white/70`、深色 `bg-white/10`（刻意用白色而非 token，以保证玻璃通透感）。

## 8. 两页差异一览（基线一致，局部增强）

| 维度 | URL 编解码 | Base64 编解码 |
|---|---|---|
| 模式切换 | 滑动玻璃分段控件 | 同左 |
| 示例按钮 | ❌ | ✅（按当前模式填明文 / 合法 Base64） |
| 标题图标 | ❌ | ✅ `Lock` / `Unlock`（编码↔解码语义） |
| 统计徽章 | `字符` | `字符 · 字节`（含 UTF-8 字节数） |
| 错误红框 | 仅顶部错误条 | 顶部错误条 + 输出区红框底色 |
| 交换清空 | 交换 + 清空 | 示例 + 交换 + 清空 |
| 错误条字体 | `font-mono` | 普通（加粗前缀） |

**统一基线**（任何同类工具页都应继承）：布局骨架、`SlidingSegmented`、面板样式、按钮规范、颜色令牌、错误条形态、明暗自适应、无障碍（radiogroup / 键盘 / `prefers-reduced-motion`）。

---

## 9. 无障碍与降级

- 分段控件：`role="radiogroup"` + 按钮 `role="radio" aria-checked` + 漫游 tabindex；支持方向键 / Home / End。
- 按钮：`focus-visible:ring-2 focus-visible:ring-primary/50`，键盘可达。
- `prefers-reduced-motion`：项目全局已关闭非必要过渡（如已回滚的 StickerPeel 默认尊重该设置）；分段控件过渡本身轻量，一般无需额外处理。
