## 工具页 SEO 模板

每个工具页面必须包含：

```
Title：{工具名} Online - Free {工具功能} Tool
Description：{工具功能描述}. Free online {工具名} with {核心特性}.
H1：{工具名}
内容：工具说明 + 使用场景 + 常见问题（总计 > 500 字）
```

示例（JSON Formatter）：
```
Title: JSON Formatter Online - Free JSON Beautifier & Validator
Desc:  Format, validate and beautify JSON online. Free JSON formatter 
       with syntax highlighting, error detection and minify support.
```
