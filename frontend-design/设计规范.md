# DevToolBox 前端设计规范

> 本文档是 UI 实现的唯一参考来源。所有色值使用 OKLCH 格式，直接对应 `app/globals.css` 中的 CSS 变量。

---

## 一、品牌定位

| 维度 | 定义 |
|------|------|
| 受众 | 开发者、工程师 |
| 调性 | 专业、简洁、快速、可信赖 |
| 差异点 | 工具本身即产品，UI 服务于效率，不做装饰 |
| 参照 | Linear（精密感）、Vercel（极简）、GitHub（可信） |

## 二、色彩系统

### 主色（Primary）

选用 **靛蓝（Indigo）**，区别于 shadcn 默认灰调，增加品牌辨识度，同时符合开发者工具的科技感。

| Token | 亮色模式 | 暗色模式 | 用途 |
|-------|----------|----------|------|
| `--primary` | `oklch(0.56 0.21 262)` | `oklch(0.72 0.17 262)` | 主按钮、选中态、焦点环 |
| `--primary-foreground` | `oklch(0.99 0 0)` | `oklch(0.14 0 0)` | 主色上的文字 |

### 背景与前景

| Token | 亮色 | 暗色 | 说明 |
|-------|------|------|------|
| `--background` | `oklch(1 0 0)` | `oklch(0.11 0.005 262)` | 页面底色，暗色含微量靛蓝色相 |
| `--foreground` | `oklch(0.14 0 0)` | `oklch(0.97 0 0)` | 主文字色 |
| `--card` | `oklch(1 0 0)` | `oklch(0.16 0.005 262)` | 卡片背景 |
| `--card-foreground` | 同 foreground | 同 foreground | |

### 辅助色

| Token | 亮色 | 暗色 | 用途 |
|-------|------|------|------|
| `--muted` | `oklch(0.97 0 0)` | `oklch(0.22 0.005 262)` | 禁用、次要背景 |
| `--muted-foreground` | `oklch(0.52 0 0)` | `oklch(0.65 0 0)` | 次要文字、占位符 |
| `--accent` | `oklch(0.95 0.02 262)` | `oklch(0.24 0.01 262)` | hover 背景、高亮行 |
| `--accent-foreground` | `oklch(0.14 0 0)` | `oklch(0.97 0 0)` | |

### 边框与输入

| Token | 亮色 | 暗色 |
|-------|------|------|
| `--border` | `oklch(0.90 0 0)` | `oklch(1 0 0 / 10%)` |
| `--input` | `oklch(0.90 0 0)` | `oklch(1 0 0 / 15%)` |
| `--ring` | `oklch(0.56 0.21 262)` | `oklch(0.72 0.17 262)` | 焦点环，与 primary 一致 |

### 语义色

| Token | 亮色 | 暗色 | 用途 |
|-------|------|------|------|
| `--destructive` | `oklch(0.58 0.24 27)` | `oklch(0.70 0.19 22)` | 错误、删除 |

### 色彩使用原则

- **主色只用于交互元素**：按钮、链接激活态、焦点环、选中态。不用于大面积背景。
- **不用多色系**：全站只有一个品牌主色，语义色（红）用于错误反馈。
- **暗色背景带微量色相**：`background` 和 `card` 在暗色模式含极低饱和度靛蓝，营造深邃感，区别于纯黑。

## 三、字体系统

### 字体家族

| 用途 | 字体 | 回退 |
|------|------|------|
| 正文 / UI | Geist Sans（变量字体） | system-ui, sans-serif |
| 代码 / 工具区 | Geist Mono（变量字体） | ui-monospace, monospace |

> 工具类页面（输入框、输出框、代码高亮）强制使用 `font-mono`，保证对齐与可读性。

### 字号比例（Type Scale）

基于 Tailwind 默认比例，以 `16px` 为正文基准：

| 级别 | Tailwind class | px | 用途 |
|------|---------------|----|------|
| xs | `text-xs` | 12 | 标签、说明文字 |
| sm | `text-sm` | 14 | 次要信息、工具栏文字 |
| base | `text-base` | 16 | 正文、卡片描述 |
| lg | `text-lg` | 18 | 分区标题 |
| xl | `text-xl` | 20 | 页面副标题 |
| 2xl | `text-2xl` | 24 | 工具页标题 |
| 3xl | `text-3xl` | 30 | |
| 4xl | `text-4xl` | 36 | 首页 Hero 标题 |

### 字重

| 用途 | class |
|------|-------|
| 正文 | `font-normal` (400) |
| 强调 / 标签 | `font-medium` (500) |
| 标题 | `font-semibold` (600) |
| Hero 大标题 | `font-bold` (700) |

### 行高

- 正文：`leading-normal`（1.5）
- 标题：`leading-tight`（1.25）
- 代码：`leading-relaxed`（1.625）

## 四、间距系统

使用 Tailwind 4 的 spacing scale（1 unit = 4px）：

| 用途 | class | px |
|------|-------|----|
| 组件内部紧凑间距 | `gap-1` / `p-1` | 4 |
| 组件内部正常间距 | `gap-2` / `p-2` | 8 |
| 元素间距 | `gap-3` / `p-3` | 12 |
| 卡片内边距 | `p-4` | 16 |
| 区块间距 | `gap-6` | 24 |
| 页面内容边距 | `px-4` | 16 |
| 页面顶部留白 | `py-12` | 48 |
| 分区间距 | `space-y-10` | 40 |

### 最大宽度

| 区域 | class |
|------|-------|
| 工具页内容区 | `max-w-6xl mx-auto` |
| 首页 / 全局导航 | `max-w-7xl mx-auto` |

## 五、圆角

基准 `--radius: 0.625rem`（10px），衍生：

| Token | 值 | 用途 |
|-------|----|------|
| `rounded-sm` | 6px | 小按钮、标签 |
| `rounded-md` | 8px | 输入框、下拉 |
| `rounded-lg` | 10px | 卡片、弹出层 |
| `rounded-xl` | 14px | 大卡片、对话框 |

## 六、阴影

开发者工具站不使用装饰性阴影，仅在以下场景使用功能性阴影：

| 场景 | 值 |
|------|-----|
| 悬浮菜单 / 下拉 | `shadow-md` |
| 模态框 | `shadow-xl` |
| 固定导航栏底部分隔 | `border-b`（不用阴影） |

## 七、动效规范

### 原则

- **功能优先**：动画服务于状态反馈，不做纯装饰
- **短促克制**：交互动画 ≤ 200ms，进场动画 ≤ 700ms
- **进场只播一次**：SplitText 等入场动画触发后不循环

### 时长参考

| 场景 | 时长 | 缓动 |
|------|------|------|
| hover 颜色变化 | `150ms` | `ease` |
| 按钮按下反馈 | `100ms` | `ease` |
| 下拉菜单展开 | `150ms` | `ease-out` |
| 主题切换 | 即时（`disableTransitionOnChange`） | — |
| SplitText 单字入场 | `700ms` | `ease` |
| SplitText 字间延迟 | `80ms / 字` | — |
| SpotlightCard 光晕淡入 | `400ms` | `ease` |

### 滚动触发

使用 `IntersectionObserver`（threshold: 0.1），进入视口后触发一次，不重复。

## 八、图标规范

使用 **Lucide React**（随 shadcn/ui 安装，无需额外引入）：

- 尺寸：`h-4 w-4`（16px，用于 UI 元素）、`h-5 w-5`（20px，用于功能入口）
- 颜色：继承文字颜色，不单独设置 fill
- 不混用其他图标库

## 九、组件规范速查

### 按钮

| 变体 | 用途 |
|------|------|
| `default` | 主操作（格式化、提交） |
| `outline` | 次要操作（压缩、导出） |
| `ghost` | 工具栏操作（清空、复制） |
| `destructive` | 危险操作 |

尺寸：工具栏按钮用 `size="sm"`，独立 CTA 用 `size="default"`。

### 卡片（工具列表）

```
SpotlightCard（外层容器）
  └─ Link（占满卡片，block p-4）
       ├─ 工具名（font-medium text-sm）
       └─ 描述（text-xs text-muted-foreground line-clamp-2）
```

### 输入输出区（工具页）

- 使用等宽字体 `font-mono text-sm`
- 高度固定 `h-80`，不随内容伸缩（保持视觉稳定）
- 错误状态：`border-destructive bg-destructive/5 text-destructive`
